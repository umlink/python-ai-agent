SSE 流式输出 POST /agent/chat/stream（骨架预留）

当前后端骨架尚未提供流式接口。阶段八 Level2/Level5 实现 SSE 后，可在此扩展： \n1. 后端新增 /agent/chat/stream 返回 StreamingResponse(media_type="text/event-stream") \n2. 前端用 fetch + ReadableStream 逐块渲染，即可呈现打字机效果。

提示：也可直接用 curl 调试 —— curl -X POST http://localhost:8000/agent/chat -H "Content-Type: application/json" -d '{"question":"你好"}'
