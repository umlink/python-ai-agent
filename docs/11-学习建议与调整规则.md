# 学习建议与调整规则（收尾）

## 学习方法论

- **重点深耕：** LangGraph 是当前企业级 Agent 开发事实标准；优先手写简易 ReAct 理解底层，再去使用框架，不要一上来就复制 Demo。
- **实践为王：** Agent 是极强工程方向；每个知识点搭配小 Demo；主动制造错误场景，复现幻觉、循环、解析失败等 Bad-case。
- **技术区分：** 区分工业落地可用技术与学术论文概念；不要沉迷 ToT / GoT 等前沿概念忽略工程落地；跟进开源社区更新。
- **体系化学习：** 原理、框架 API、工程化部署、业务落地四部分缺一不可；只会调库遇到线上问题完全无法排查。

## 时间不足的调整规则

- 单周任务无法完成时，优先保「核心任务」列，选学内容 🟡 往后顺延。
- 连续两周动态规划类内容无法推进时，暂停扩展、回头补阶段一异步与状态机基础。

## 复盘规则

- 每周末盘点本周完成 demo 数量、复现的 Bad-case 数、自检清单通过率。
- 不达标项写入下周首日修复，避免滚动欠账。

## 边界认知

- 本大纲聚焦应用层 Agent 开发，不含大模型预训练、SFT、RLHF 微调。
