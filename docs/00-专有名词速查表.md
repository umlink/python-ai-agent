# 专有名词速查表

> 按主题集中解释文中专有名词，遇到陌生词随时回查。

## 大模型与基础概念

| 术语               | 用途（做什么）                                         |
| ---------------- | ----------------------------------------------- |
| LLM              | 大语言模型，Agent 的「大脑」；本大纲只讲应用层调用，不涉及训练              |
| Token            | 模型处理文本的最小单位；中文 1 字约 1\~2 token，计费按 token        |
| 上下文窗口            | 模型单次能「看到」的最大 token 数，超出需截断或压缩                   |
| 采样参数             | temperature / top-p / top-k 控制随机性；工具调用建议 0\~0.3 |
| Embedding        | 把文本转成高维向量，语义相近则向量距离近；RAG 底座                     |
| OpenAI 兼容接口      | 统一 chat/completions 格式，改 base\_url 即可切换模型       |
| Function Calling | 模型按 tools Schema 输出「调用哪个工具、传什么参数」               |
| Prompt 工程        | 设计指令让模型稳定输出符合要求的结果                              |
| Few-shot         | 提示中放入若干「输入→输出」示例让模型模仿                           |
| CoT              | 思维链，引导模型先逐步推理再给答案                               |
| 幻觉               | 模型生成看似合理但为编造的内容；靠检索溯源抑制                         |
| Ollama / vLLM    | 本地跑模型（调试）/ 高吞吐推理服务（生产）                          |

## AI Agent 核心概念

| 术语                | 用途（做什么）                     |
| ----------------- | --------------------------- |
| Agent             | 能自主「感知→规划→调用工具→反馈迭代」闭环的程序   |
| RAG               | 先从知识库检索相关片段再作答，缓解幻觉、支持引用溯源  |
| ReAct             | 思考→行动→观察 循环，最基础 Agent 范式    |
| Plan-and-Execute  | 先生成完整计划再逐步执行，适合长周期任务        |
| Reflexion         | 失败后反思错误再重试                  |
| AutoGPT           | 自主目标拆解循环执行；原型惊艳但生产可控性差      |
| ToT / GoT         | 思维树 / 思维图，推理开销巨大，工业落地极少     |
| MAS               | 多智能体系统：流水线、分层管控、辩论校验、黑板四种模式 |
| Human-in-the-loop | 高危节点插入人工确认，提升可靠性与合规性        |
| Checkpointer      | 把 Agent 状态落盘，支持中断后恢复执行      |
| 短期/工作/长期记忆        | 当前会话 / 本任务中间态 / 跨会话持久化      |
| Bad-case          | 效果差的输入样本，归类后驱动迭代优化          |
| Devin             | AI 软件工程师概念产品，AI 研发助手的范式参考   |

## 主流框架与平台

| 术语                   | 用途（做什么）                             |
| -------------------- | ----------------------------------- |
| LangChain            | 模型封装、Prompt 模板、Chain、Tools 等基础组件脚手架 |
| LangGraph            | 图状态化 Agent 框架，企业生产级 Agent 事实标准      |
| LlamaIndex           | 数据接入、分块、索引、检索一体化的 RAG 框架            |
| CrewAI               | 角色化多智能体框架，内容创作原型上手快                 |
| AutoGen              | 微软多 Agent 框架，Agent 间自然语言对话协作；⚠️ 已进维护模式，新框架为 Microsoft Agent Framework（MAF） |
| Semantic Kernel      | 微软插件化框架，适合 Python / .NET 混合团队；⚠️ 已并入 MAF 进入维护模式 |
| Assistants API       | OpenAI 托管式 Agent，快速原型；逻辑黑盒          |
| Dify                 | 低代码 Agent 平台，快速验证业务思路               |
| MCP                  | Model Context Protocol，Agent 工具接入的标准协议（跨进程共享工具，见阶段四） |
| LangSmith / LangFuse | 链路追踪与评测平台                           |
| Ragas                | RAG 评估库：忠实度 / 答案相关性 / 检索质量指标      |
| Streamlit            | Python 快速 Web 框架，给 Agent Demo 做前端   |

## 工程工具与基础设施

| 术语                           | 用途（做什么）                         |
| ---------------------------- | ------------------------------- |
| pydantic v2                  | 数据校验库，生成 JSON Schema，兜底解析脏 JSON |
| loguru                       | 结构化日志，记录 Agent 全链路输入输出          |
| tenacity                     | 声明式重试策略，专治 LLM 网络抖动             |
| python-dotenv                | 从 .env 读取密钥与配置                  |
| FastAPI                      | 高性能 Web 框架，自动校验入参、支持 SSE 流式     |
| SSE / WebSocket              | 服务器单向推送文本流 / 双向长连接              |
| Docker / Compose             | 打包应用成镜像 / 一键拉起整套环境              |
| K8s                          | 容器集群编排：自动扩缩容、滚动发布               |
| Redis / PostgreSQL / MongoDB | 会话缓存 / 结构化业务数据 / 非结构化记忆         |
| pgvector              | PostgreSQL 向量扩展：向量与业务数据同库、事务一致，中小规模首选 |
| pytest / ruff / mypy         | 单测 / 代码风格检查 / 静态类型检查            |
| OpenTelemetry         | 可观测性标准协议：一次埋点、trace/指标/日志多后端（Langfuse/LangSmith 均支持 OTLP 接入） |

| AgentBench / GAIA             | 公开 Benchmark，仅供横向认知           |
