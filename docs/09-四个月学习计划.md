# 四个月学习计划（每周任务版，共 16 周）

> 计划假设：工作日 ≥ 1 小时 + 周末 ≥ 4 小时的业余学习强度；时间不足时可拉长周期，只需保持每周末做一轮「复盘与调整」。

## 每周任务表

| 周次 | 核心任务 | 阶段映射 |
|-|-|-|
| 第 1-2 周 | Python 基础巩固 + 进阶语法 + 类型注解；完成 pydantic v2 / loguru / tenacity / dotenv 的最小练习；搭好项目骨架 + 虚拟环境 + 单测 + ruff | 阶段一 · Python 与工具库 |
| 第 3 周 | 并发异步：asyncio + httpx 并发调用 LLM、超时与限流、SSE 解析；FastAPI 实现一个流式接口 | 阶段一 · 并发与 API |
| 第 4 周 | 大模型原理（Token、上下文、采样参数）；主流模型 API 实操（至少一家国内 + 一家国际）；Ollama 本地部署 | 阶段一 · 大模型与 API |
| 第 5 周 | Prompt 工程核心 + Function Calling 完整链路；本地跑通一次工具调用全流程 | 阶段一 · Prompt 工程 |
| 第 6 周 | Agent 理论基础：四大组件 + 四种范式 + 失败模式；手写简易 ReAct Agent（不依赖框架） | 阶段二 |
| 第 7-8 周 | LangChain 基础 + LangGraph 核心（State / Node / Edge / 持久化）；完成 Level1 ReAct 智能问答 Agent | 阶段三 + 阶段八 Level1 |
| 第 9-10 周 | LlamaIndex 数据处理链路 + RAG 进阶；本地向量库（Qdrant）+ 混合检索 + Rerank；完成 Level2 知识库 RAG Agent | 阶段三 + 阶段四 + Level2 |
| 第 11 周 | 工具生态补齐（搜索 / 代码执行 / 文件处理 / 业务系统）；自定义工具开发规范四项落地 | 阶段四 · 工具生态 |
| 第 12 周 | Level3 多角色内容创作团队（CrewAI 或 LangGraph 多智能体）；或转入本阶段已渗透的垂直项目 | 阶段三 CrewAI/AutoGen + Level3 |
| 第 13-14 周 | Level4 数据分析 Agent（SQL Agent + Pandas + 图表 + 报告）；同步落地阶段四向量库与阶段五评测方法 | 阶段八 Level4 + 阶段五部分 |
| 第 15-16 周 | Level5 企业智能客服 Agent：状态持久化 + 权限 + 监控告警 + 评测闭环；Docker Compose 一键部署；Doc 交付与复盘 | 阶段六 + 阶段七 + Level5 |

## 节奏说明

- 阶段五（多智能体进阶 / 记忆优化 / 安全对齐）不适合孤立学习，建议在 Level3-5 项目实践中穿插吸收。
- 阶段六的五个垂直方向按「必须完成一个、了解其余」处理。
