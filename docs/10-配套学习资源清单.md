# 配套学习资源清单

> 筛选标准：优先官方文档与活跃开源仓库（时效性较好）；论文类仅用于阶段二 / 五建立原理认知；每条给出用途与注意点。

## 官方文档（框架主来源）🔴

| 资源                                                              | 用途                                                                                                      |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [LangChain / LangGraph 官方文档](https://python.langchain.com/docs) | 阶段三主体；优先看 LangGraph Conceptual Guide 与 Tutorials（Quick Start、Persistence、Human-in-the-loop、Multi-agent） |
| [LlamaIndex 官方文档](https://docs.llamaindex.ai)                   | RAG 与文档感知 Agent；看 Data ingestion、Retrievers、Agent 章节                                                    |
| [CrewAI 官方文档](https://docs.crewai.com)                          | 多智能体快速原型；对照 LangGraph 理解「角色化 vs 图状态」差异                                                                  |
| [AutoGen 官方文档](https://microsoft.github.io/autogen/)            | 对话式多 Agent 与代码执行实验；注意沙箱安全边界                                                                             |
| [OpenAI 官方文档](https://platform.openai.com/docs)                 | Function Calling、Responses API、Assistants；理解工具调用链路最佳对照                                                  |
| [Dify 官方文档](https://docs.dify.ai)                               | 低代码平台；快速验证业务思路，理解工作流与 LangGraph 编排的等价概念                                                                 |
| [vLLM 官方文档](https://docs.vllm.ai)                               | 本地高吞吐推理部署；了解 OpenAI 兼容接口封装                                                                              |

## 开源项目（抄作业 + 读源码）🔴

- LangChain 官方示例仓库（langchain-ai/langchain 的 cookbook / docs 示例）：每个框架概念配一个最小可跑 demo。

- LangGraph 官方 Templates（langchain-ai/langgraph 的 examples）：成熟单 / 多 Agent 参考实现，重点读 State、Checkpointer 用法。

- LlamaIndex 官方文档示例与 llamaindex 仓库 examples：RAG 全链路参考。

- CrewAI 官方 Examples 仓库（crewAIInc/crewAI 的 examples 目录）：角色化多智能体场景。

- AutoGen 官方 examples：对话多 Agent 与 GroupChat 模式。

- 开源垂直 Agent（企业客服、数据分析助手类）：学习工程分层与工具封装（按最新开源热度筛选）。
